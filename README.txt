TRTBR CLOTHING WEBSITE
=======================

This is a free, editable static clothing-store website.

FILES
- index.html
- assets/trtbr-logo.jfif

HOW TO EDIT PRODUCTS
1. Open index.html in a text editor such as Notepad.
2. Find: "EDIT YOUR PRODUCTS HERE"
3. Change the product name, price, sizes, badge and image.
4. Save the file.
5. Upload the updated files to your free hosting.

PRODUCT IMAGE
To use a product photo:
- Put the photo inside the assets folder.
- Example: assets/black-tee.jpg
- In the product data, set image: "assets/black-tee.jpg"

FREE HOSTING
You can host this website free using GitHub Pages. No monthly hosting payment is required.
A custom .com domain is optional and normally costs money.

ORDER FLOW
Customers add products to the cart, prepare an order, copy the order details, then open Messenger.
Facebook page: https://www.facebook.com/gwapogiiiofficial
Messenger: https://m.me/gwapogiiiofficial

NOTE
This version does not process online payments or store customer orders in a database. It is designed as a zero-cost storefront/order-request website.
